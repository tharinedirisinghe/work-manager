# Work Manager

A lightweight personal project and task manager, inspired by Jira and Skapp but built for one person.
It runs in the browser, installs as a desktop app, works offline, and keeps all data on your own device.

## Features

- **Projects** with keys (`PORT-12`), colors and archiving
- **Kanban board** (Backlog → To Do → In Progress → Done) with drag and drop, plus a filterable **list view**
- **Tasks** with priority, labels, due date, estimate, Markdown description and a checklist
- **Time tracking**: one-click timer (survives reloads), manual entries, estimate vs. actual
- **Comments and activity history** in one timeline per task
- **Today view**: in progress, overdue, planned for today, due today
- **In-progress limit**: a soft warning when you start too many things at once
- **Quick add** (`Ctrl+K` or `N`): `Fix nav !high #portfolio due:fri ~2h @today`
- **Automatic weekly review** every Monday, with stats and rule-based insights. Optional AI report through
  claude.ai (free, copy and paste) or your own Anthropic API key
- **Data safety**: persistent storage, automatic daily JSON backups to a folder you pick (Edge/Chrome), manual export and import
- Dark mode and keyboard shortcuts (`?` lists them)

## Design

- **Calm palette:** warm neutral surfaces with one muted sage-teal accent. Red, amber and green are reserved for meaning
  (overdue, warnings, done). All text colours meet WCAG AA contrast in light and dark themes.
- **Design tokens** live as CSS variables in `src/index.css` (`canvas`, `surface`, `ink`, `accent`, …). Shared
  button/input styles are in `src/components/styles.ts`.
- **Icons:** one family ([Lucide](https://lucide.dev)), 16px in content and 18px in navigation, 1.75 stroke, always
  paired with a text label or tooltip.
- **Type:** Inter (bundled, so it works offline), with tabular figures for timers and counts.
- **Logo:** three cards stepping up and to the right, showing work moving from backlog to done
  (`src/components/Logo.tsx`, `public/favicon.svg`, PNGs generated by `npm run icons`).

## Privacy

There is no server and no account. Data lives in the browser's IndexedDB on your computer, tied to the browser profile
and the site's address. The hosted site only serves the app's code. If you use the optional API key, it is stored
locally and sent only to Anthropic, and only the week's stats and task titles are sent (no descriptions or comments).

## Development

```bash
npm install
npm run dev       # http://localhost:5173/work-manager/
npm test          # unit tests (Vitest + fake-indexeddb)
npm run build     # type-check and production build into dist/
npm run preview   # serve the production build (installable PWA)
npm run icons     # regenerate public/icon-*.png
```

Stack: React, TypeScript, Vite, Tailwind CSS, Dexie (IndexedDB), Zustand, dnd-kit, vite-plugin-pwa.

## Deploy to GitHub Pages

1. Create a **public** GitHub repo named `work-manager` and push this project to `main`.
2. In the repo, open **Settings → Pages** and set **Source** to **GitHub Actions**.
3. Every push to `main` runs the tests, builds, and publishes to `https://<your-username>.github.io/work-manager/`.

If you use a different repo name, change `base` in `vite.config.ts` to match.

## Install as an app

Open the site in Edge or Chrome and click the **Install** icon in the address bar (or **⋯ → Apps → Install**).
Work Manager then gets a Start menu and desktop icon, opens in its own window, and works offline. Updates install
automatically the next time it starts after you push changes.
